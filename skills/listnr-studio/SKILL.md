# Listnr Studio

Use this skill when the user wants an AI video, text-to-video short, voiceover video, captions, or a Studio tool such as Prompt to Video or AI Movie Maker.

## Quick start

1. GET https://studio.listnr.ai/api/v1/tools to pick a `toolId`.
2. Open https://studio.listnr.ai/create?tool=<toolId>.
3. MCP: https://studio.listnr.ai/mcp
4. OpenAPI: https://studio.listnr.ai/openapi.json

## Do not

Generate or bill from the public Studio host. Send the person into `/create`.
